# EEC MOZ — website

Site da EEC MOZ (@eecmoz), material electrónico e de escritório em Maputo, desde 2009.

- Página única (`index.html`) com palco 3D (three.js) e animação ao scroll (GSAP + Lenis)
- Logo e cores tiradas do perfil de Instagram da marca
- Alojado no GitHub Pages (branch `main`, raiz)

Cada push para `main` atualiza o site em cerca de 30 segundos.
